Report campus problems, track progress, and ensure faster resolutions for a better campus experience.

How It Works

1. Submit Issue

Students submit complaints related to classroom, hostel, lab, or security.

2. Review & Assign

Admin reviews the issue and assigns it to the concerned department.

3. Resolve

Maintenance staff resolves the issue based on priority.

4. Close

Status is updated and students are notified after resolution.

Key Features

  • Category-wise complaint tracking
  • Priority-based issue handling
  • Status tracking (Submitted → In Progress → Resolved)
  • Admin dashboard overview
  • Resolution time monitoring
  • Email / notification simulation

User Roles 🎀

Student

Submit complaints and track resolution status.

Admin

Manage complaints, assign tasks, and monitor performance.

Maintenance Staff

Resolve assigned issues efficiently.
